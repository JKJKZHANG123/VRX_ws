# 突发障碍物避障实验报告

**日期**: 2026年9月2日  
**实验目标**: 验证USV在航行过程中遭遇突然出现的障碍物时的避障能力  
**系统配置**: Point-LIO + Nav2 + SmacPlannerHybrid + RegulatedPurePursuitController

---

## 一、实验设计

### 1.1 实验场景

在航行过程中，当船只速度≥0.25 m/s且已行驶≥4.0 m后，在船只前方指定距离处突然生成一个静态障碍物（1.5m × 1.5m × 2.0m 立方体），测试系统的动态避障响应能力。

### 1.2 实验参数

| 参数 | 说明 |
|------|------|
| 目标点 | (24, 0) m in camera_init frame |
| 障碍物尺寸 | 1.5m × 1.5m × 2.0m |
| 触发条件 | 船速 ≥ 0.25 m/s 且已行驶 ≥ 4.0 m |
| 横向偏移 | 0.5 m（障碍物相对航线右侧） |

### 1.3 实验变量

- **触发距离**: 障碍物出现在船头前方的距离
  - sudden01: 12.0 m（失败，未达到触发条件）
  - sudden02: 8.0 m（成功）

## 三、关键发现

### 3.1 避障能力验证

✅ **系统在8m触发距离下成功避障并到达目标**

- 船速仅0.31 m/s（较低速度）时触发，系统仍有充足时间响应
- 最近接近距离7.05 m，安全裕度充足
- 横向偏移1.75 m，避障动作幅度合理

### 3.2 系统响应特性

1. **障碍物检测**: LiDAR实时扫描，障碍物立即进入costmap
2. **路径重规划**: SmacPlannerHybrid (Dubins运动模型) 生成可行路径
3. **控制执行**: RegulatedPurePursuitController平滑跟踪避障轨迹
4. **安全保障**: 
   - costmap膨胀半径3.8m保证安全间距
   - 船体footprint 5.9m×3.2m被正确考虑
   - 独立的safety_cloud紧急停车系统（本次未触发）

### 3.3 实验局限性

1. **sudden01失败原因**
   - 实验设计未考虑系统在目标完成后的静止状态
   - 需要在每次实验前确保Nav2处于激活且正在执行目标的状态

2. **单一成功样本**
   - 仅有sudden02一次成功实验
   - 8m触发距离在0.31 m/s船速下充足，但更高船速或更近触发距离未测试

3. **触发距离覆盖不足**
   - 原计划测试12m和8m两个触发距离
   - 实际仅验证了8m
   - 缺少更极端条件（6m、4m）的测试数据

3. ✅ 平滑执行避障机动

## 五、后续工作建议

### 5.1 补充实验

1. **扩展触发距离测试**
   - 12m（重新测试，确保初始运动状态）
   - 6m、5m、4m（逐步逼近最小安全距离）
   - 找到系统避障的临界触发距离

2. **变化船速测试**
   - 低速: 0.3 m/s（已测试）
   - 中速: 0.6 m/s（期望巡航速度）
   - 高速: 0.8~1.0 m/s（接近系统速度上限）

3. **变化横向偏移**
   - 中心线: 0.0 m（正面碰撞风险最高）
   - 当前: 0.5 m
   - 更大偏移: 1.0 m、1.5 m

4. **多障碍物场景**
   - 连续障碍物（前方依次出现）
   - 并行障碍物（同时出现在不同位置）

### 5.2 系统改进方向

1. **实验框架改进**
   - 在`run_sudden_obstacle_trial.sh`中加入Nav2状态预检
   - 确保每次实验前船只处于运动状态
   - 添加触发条件超时后的自动重试逻辑

2. **安全裕度量化**
   - 基于多次实验统计最小安全距离的分布
   - 建立触发距离、船速与安全裕度的关系模型

3. **动态障碍物跟踪**
   - 当前实验使用静态障碍物
   - 未来可测试`USV_DYNAMIC_TRACKER=true`模式
   - 验证运动障碍物的轨迹预测和避障
